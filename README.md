# ecommerce-smartcart

##  Overview
SmartCart is a user segmentation system for e-commerce platforms.  
It applies clustering techniques to group users into 4 distinct categories based on their shopping behavior, preferences, and activity.  

This project demonstrates the use of data science and machine learning for customer analytics, helping businesses better understand their audience.

---

##  Features
- Clusters e-commerce users into 4 meaningful groups.
- Uses machine learning algorithms for segmentation.
- Provides insights into customer behavior and shopping patterns.
- Can be extended for personalized recommendations and targeted marketing.
